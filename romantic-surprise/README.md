# Romantic Surprise 💌

Plain HTML/CSS/JS. No install needed.

## Run
Double-click `index.html`, or for a local server:
    python3 -m http.server 8000
then open http://localhost:8000

## Customise (everything is in config.js)
- Password: `password`
- Photos: put 8 images in `photos/` named photo1.jpg ... photo8.jpg (or change paths) and edit captions
- Song: put your file at `music/song.mp3`, change the title
- Letter: edit `letter`

## Share
Upload the whole folder to Netlify Drop or GitHub Pages and send her the link.
